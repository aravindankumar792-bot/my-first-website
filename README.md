# SB Travels - Booking Website

This is a travel booking website created using HTML, CSS, and JavaScript.  
The website allows users to submit booking details which are automatically stored in Google Sheets using a custom API endpoint.

## Features
- Responsive landing page
- Booking form with validation
- Google Sheet integration using API
- Auto-save customer data in spreadsheet
- Modern UI with custom CSS
- Deployed using GitHub Pages

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Apps Script API
- Git & GitHub

## How to Use
1. Open the website  
2. Fill in booking details  
3. Submit form  
4. Data is saved in Google Sheet automatically
